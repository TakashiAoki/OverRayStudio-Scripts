## English

A collection of scripts I actually use in production for motion graphics and FUI (Fictional UI) design work on anime and sci-fi productions. Built primarily for Adobe After Effects, optimized for the workflows used on Japanese animation compositing teams.

### Scripts

| Script | Summary | Target |
|---|---|---|
| [CSUM_GotoTime](CSUM_GotoTime/) | Jump the timeline by anime-timesheet notation | After Effects |
| [UILabelGenerator](UILabelGenerator/) | UI label generator | After Effects |
| [AdobeApiBridge](AdobeApiBridge/) | Bridge for Adobe app integration | Python / Adobe |

### What is CSUM?

CSUM stands for **C**omposite **S**peed **U**p **M**odule — a script suite I started building in 2007 for anime compositing. The CSUM tools assume the Japanese-anime convention of 24 fps timelines that start at frame 1 (not frame 0), and provide controls aligned with traditional timesheet (タイムシート) workflows.
